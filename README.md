# odin-rock-paper-scissors

JS Rock Paper Scissors game played from the console. This is for the first JavaScript assignment in The Odin Project's Foundation Course.

https://www.theodinproject.com/paths/foundations/courses/foundations

### Directions:
- Open index.html > F12 to open dev tools > select Console
- User is prompted to input a number from 1 - 3 
    - 1 for Rock
    - 2 for Paper
    - 3 for Scissors
- The computer will randomly choose a selection
- The game consists of 5 rounds
