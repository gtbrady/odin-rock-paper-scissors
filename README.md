# odin-rock-paper-scissors


JS Rock Paper Scissors game played from the browser. The original assignment below was to create a Rock Paper Scissors game played from the console. 

https://www.theodinproject.com/lessons/foundations-rock-paper-scissors
https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors

The current implementation is a follow up assignment adding a GUI. 

### Directions:
- Hit the Start Game button to begin the game
- Hit one of the three options to make a selection for the round
- The game is played against the computer, best of 9 (first to 5)
